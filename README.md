# MR CLI FOR FFMPEG v1.0.0

**Консольный интерфейс для редактирования и конвертирования видео на базе FFmpeg**

## 📋 Описание

MR CLI FOR FFMPEG — это удобная консольная программа-обёртка над FFmpeg, предоставляющая интуитивное меню для выполнения разнообразных операций с видео и аудио файлами без необходимости запоминать сложные команды FFmpeg.

## ✨ Возможности

### Видео операции
- **Конвертация форматов** — MP4, MKV, WEBM, AVI, MOV с поддержкой кодеков H.264, H.265/HEVC, AV1, VP9
- **Обрезка видео** — Trim/Cut с указанием времени начала и конца
- **Изменение разрешения** — от 360p до 4K с фильтром Lanczos
- **Изменение скорости** — ускорение/замедление от 0.25x до 100x
- **Поворот и отражение** — 90°, 180°, 270°, зеркалирование
- **Сжатие видео** — с настраиваемым CRF и визуализацией экономии размера
- **Добавление водяного знака** — с выбором позиции (углы, центр)
- **Вшивание субтитров** — burn-in для SRT/ASS/SSA/VTT

### Аудио операции
- **Извлечение аудио** — в MP3, M4A, WAV, FLAC, OGG
- **Слияние видео + аудио** — объединение дорожек
- **Удаление звука** — создание беззвучной версии

### Прочее
- **Склейка файлов** — объединение нескольких видео/аудио
- **Создание GIF** — двухпроходное с палитрой для качества
- **Извлечение кадров** — одиночный кадр, по интервалу, каждый N-й
- **Информация о файле** — детальный анализ через FFprobe

## ⚙️ Настройки

- Формат вывода (10+ форматов)
- Разрешение, FPS
- Пресет кодирования (ultrafast → veryslow)
- CRF (качество), битрейт аудио
- Аппаратное ускорение
- Перезапись файлов, сохранение метаданных
- Автоматическая установка FFmpeg

## 🛠️ Сборка

Требования:
- Visual Studio 2022 (v143 toolset)
- Windows SDK 10.0
- C++17

```
msbuild mr-cli-ffmpeg.sln /p:Configuration=Release /p:Platform=x64
```

## 📦 Установка

При первом запуске программа предложит автоматически скачать и установить FFmpeg (~160 МБ).
