# MR CLI FOR FFMPEG

> **Language:** Русский · [English](README.en.md)

## Описание

MR CLI FOR FFMPEG — это удобная консольная программа-обёртка над FFmpeg, предоставляющая интуитивное меню для выполнения разнообразных операций с видео и аудио файлами без необходимости запоминать сложные команды FFmpeg.

## Возможности

### Видео операции
- **Конвертация форматов** — MP4, MKV, WEBM, AVI, MOV с поддержкой кодеков H.264, H.265/HEVC, AV1, VP9
- **Обрезка видео** — Trim/Cut без перекодирования с точным расчётом времени и отображением прогресса/ETA
- **Изменение разрешения** — от 360p до 4K с фильтром Lanczos и авто-деинтерлейсингом чересстрочного видео
- **Изменение скорости** — плавное ускорение/замедление от 0.25x до 100x с цепочкой аудиофильтров `atempo`
- **Поворот и отражение** — 90°, 180°, 270°, зеркалирование по горизонтали и вертикали
- **Сжатие видео** — с настраиваемым CRF, пресетами качества и визуализацией экономии размера
- **Добавление водяного знака** — наложение изображений (PNG) с выбором позиции (углы, центр)
- **Добавление субтитров** — отдельная отключаемая дорожка (Softsub) или вшивание в кадры (Hardsub) с интерактивным разрешением конфликтов контейнеров (MP4/MKV)
- **Умная обработка GPU & совместимости** — автоматическое выравнивание нечётных разрешений под требования аппаратных энкодеров (NVENC/AMF/QSV), определение аппаратных лимитов 8K/4K и авто-микширование звука в стерео для MP3

### Аудио операции
- **Извлечение аудио** — в MP3, M4A, WAV, FLAC, OGG с автоматическим стерео-микшированием для MP3
- **Слияние видео + аудио** — объединение дорожек без перекодирования видеоряда
- **Удаление звука** — создание беззвучной версии (Mute)

### Прочее
- **Склейка файлов** — объединение нескольких видео/аудио
- **Создание GIF** — двухпроходное с генерацией оптимизированной палитры
- **Извлечение кадров** — одиночный кадр, по временному интервалу или каждый N-й кадр
- **Информация о файле** — детальный анализ дорожек и метаданных через FFprobe
- **Сравнение двух файлов** — наглядная таблица сравнения характеристик с подсветкой различий

### Пакетная обработка
- **Пакетное сжатие видео** — поочерёдное сжатие всех видео в папке с сохранением дорожек и разрешением конфликтов
- **Пакетное сжатие аудио** — поочерёдное сжатие всех аудиофайлов в папке с пакетными пресетами

## Настройки

- Формат вывода (MP4, MKV, WEBM, MOV, AVI, MP3, M4A, WAV, FLAC, OGG) с подменю пресетов и битрейта
- Разрешение, FPS
- Пресет кодирования (ultrafast → veryslow) со стрелочной навигацией и описаниями
- CRF (качество) с пресетами и ручным вводом
- Битрейт аудио с пресетами и ручным вводом
- Свои аргументы FFmpeg (Custom FFmpeg args)
- Аппаратное ускорение: CPU (libx264), NVIDIA (NVENC), Intel (QSV), AMD (AMF), Гибридный (CPU+GPU), Обратный гибридный (GPU+CPU)
- Автоопределение GPU и процессора с отображением на главном экране
- Перезапись файлов, сохранение метаданных
- Запрос кодека перед обработкой (видео/аудио)
- Автоматическая установка FFmpeg
- Двуязычный интерфейс (русский / английский)

## Сборка

Требования:
- Visual Studio 2022 (v143 toolset)
- Windows SDK 10.0
- C++17

```
msbuild mr-cli-ffmpeg.sln /p:Configuration=Release /p:Platform=x64
```

## Установка

При первом запуске программа предложит автоматически скачать и установить FFmpeg (~160 МБ).
